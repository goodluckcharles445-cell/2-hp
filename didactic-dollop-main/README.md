# Thinkficial Engineering Network (T.E.N.) Website

This package contains the complete static website for Thinkficial Engineering Network, including Home, About & Services, Management Team, TEN Academy, and Contact pages.

## Run locally

Open `index.html` in a browser, or open this folder in Visual Studio Code and use a local static server extension.

## Publish

Copy the contents of this folder into your intended website repository, then commit and push your changes.

## Contact form

The contact form prepares an enquiry for the visitor to send using their own email application or WhatsApp. It does not store messages in a database or send them server-side.

## Design

The design uses a premium corporate palette, responsive navigation, consistent typography and spacing, refined cards, and responsive layouts across the core pages.
